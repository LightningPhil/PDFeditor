# Example PDFs

Drop your example PDF files into this folder:

`F:\WebDev\PDFeditor\samples`

They are ignored by Git, so they will stay off GitHub. Nested folders are fine.
The app does not automatically read this folder; drag a file from here onto the app.

Useful examples include:

- A normal text document with a few specific words you want changed.
- A document with unusual fonts, columns, tables, or coloured backgrounds.
- A scanned PDF (if you need editing of scanned text).
- A multipage PDF for page insertion, removal, and reordering.

If possible, include a short `.txt` note beside each PDF describing a desired edit.
Notes are ignored too. Avoid irreplaceable originals; export edits to new files.
